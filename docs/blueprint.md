# **App Name**: GitWrap

## Core Features:

- GitHub Username Input: Allows users to enter their GitHub username to fetch data.
- Data Fetching: Fetches user's GitHub activity data for the year 2025 using the GitHub API.
- Stats Generation: Calculate statistics based on fetched data, including contributions, languages used, and commits.
- Achievements Unlocking: Generates achievements using GitHub activity data for milestones.
- Annual Report Generation: Generates roast for the user's GitHub Activity data. A tool will analyze the data and provide tailored feedback.
- Visual Report: Displays the generated statistics and achievements in a visually appealing report.
- Card Export: Generates and downloads card using user information.

## Style Guidelines:

- Primary color: Modern gradient from dark blue (#0A0A50) to light blue (#ADD8E6) to symbolize technology and innovation.
- Background color: Very dark blue (#1A142B) for contrast, so that bright accent colors pop from a dark surface.
- Accent color: Light green (#96D3A0) to convey trust, cleanliness, and efficiency, for interactive elements and highlights.
- Body and headline font: 'Inter', a sans-serif, which is suitable for headlines or body text
- Use minimalist icons from 'lucide-react' to represent different stats and achievements.
- Employ a modern layout with clear sections for stats, achievements, and the generated report.
- Incorporate smooth transitions and loading animations using Framer Motion to enhance user experience.
